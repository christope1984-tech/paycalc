지우개

지우는 방식
펜 버튼으로 지우개

눌러서 전환: 펜을 띄운 채 버튼을 한 번 누를 때마다 펜↔지우개. 누르는 동안: 버튼을 누르고 있을 때만 지우개(이 태블릿은 버튼을 누른 채 화면에 대면 신호가 거의 안 들어와서 잘 안 지워져요).

펜 버튼 확인

아래 번호를 먼저 누르고 그 동작을 해 주세요. ① 그냥 한 번 긋기 ② 펜 버튼을 누른 채 긋기 → 펜 떼기 → 다시 버튼 누른 채 긋기 ③ 펜 버튼을 누른 채 화면에 닿지 않게 띄워서 움직이기 ④ 펜 버튼을 누른 채 화면에 대고, 떼지 말고 3초쯤 문지르기. 끝나면 기록을 복사해 보내 주세요.

넣을 검토 의견

          
체크리스트에서 고른 내용으로 자동으로 만들어져요. 누르면 넣음↔뺌. '시크릿'은 보고서에서 흐리게 가리고 '계약 후 공개'로 보여요. 보완점의 '중요'를 누르면 빨간 '중요 보완점'으로 바뀌어 앞쪽에 들어가요.

          

        
보완점 추가

          
대표님께 함께 안내할 내용을 고르세요. 고른 것만 '보완점' 카드로 들어가요.

          

        
여성기업 정책자금 비교

          
'안내한 내용'에 여성기업확인서를 고르면 요약에 이자 비교표가 들어가요. 금리는 신청 시점 공고에 맞춰 고쳐 주세요.

          

          
          

        
설명 수준

          
핵심만: 검토 의견에서 설명 문단을 빼고 현황과 '저희가 할 일'만 넣어요. 기존 세무사가 있는 업체는 처음에 핵심만으로 열려요.

          

        
추가 의견 (선택)

          

        
규칙으로 만든 사전 검토라 실제 자료를 보면 달라질 수 있어요. 보내기 전에 오른쪽 미리보기를 꼭 읽어 보세요. 사무소명·연락처는 설정 → 기본값에서 넣어요.
